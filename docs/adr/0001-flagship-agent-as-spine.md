# The Flagship Agent is the course's spine; non-contributing modules become an Appendix

The repo had 17 independent topic modules and 3 stars, while the 2026 breakout learning repos share one "build X from zero" through-line. We restructure around a single Flagship Agent that each Spine module changes, and move modules that don't change it into an Appendix instead of deleting them. The goal is credibility with engineers shipping agents, not topic coverage.

## Considered Options

- **Two products in one repo** (flagship track plus a separate 17-module book): rejected because it keeps the diluted pitch.
- **A new flagship repo**, with this one kept as the reference: rejected because it restarts from zero stars and splits maintenance.
