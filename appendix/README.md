do not change the Flagship Agent; they are here for when you want the full picture of
one subject.

Each topic folder has a README and, for the Python topics, a notebook and its own
`requirements.txt`. Run notebooks from inside their folder, with the repo's `.env` at
the root (`cp .env.example .env`).
